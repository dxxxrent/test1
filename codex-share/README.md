# FDE 的 Codex 修改、校验、记录流程分享包

版本：v3，2026-10-22。适用于将 FDE 的协作流程接入其他代码项目。

**复制文件夹后初始化一次，再在目标项目根目录新建 Codex 聊天。之后直接提出需求即可沿用流程，无需每次粘贴完整提示词。**

```text
另一个项目/
  codex-share/
  该项目的源码、配置和测试...
```

在另一个项目根目录执行：

```powershell
python codex-share/install.py
```

安装器合入项目根的有效 AGENTS 指令文件，复制或保留两项项目 Skill。已有规则和不同内容的同名 Skill会保留，原指令文件变化前另存备份。重复安装不会重复添加规则块。

仅复制到普通子文件夹不会让 Codex 自动读取父项目规则，这是 Codex 的指令发现范围决定的。初始化后新建聊天/会话，继续使用该项目自己的语言、测试和业务约定。

## 工作流程

理解需求 → 查看现状 → 必要修改 → 按影响校验 → 复核实际结果 → 落盘记录与交接。

- `START-HERE.md`：接入、检查和后续使用步骤。
- `install.py`：一次性接入、只读检查和预览；不运行模型或业务任务。
- `WORKFLOW.md`：接入后由项目规则引用的通用执行流程。
- `integration/AGENTS.block.md`：合入项目根的简短规则。
- `docs/`：流程、环境、校验与边界说明，含官方指令加载依据。
- `starter/.agents/skills/`：文档需求处理和 Git 改动 UI 检查两项原样技能。
- `prompts/`、`templates/`：可选的详细任务入口和记录格式。
- `examples/fde/`：FDE 特定上下文和历史验收示例，不能作为其他项目事实直接使用。
- `tests/test_install.py`：在隔离项目中核对接入行为。
- `PACKAGE-CHECKS.md`、`manifest.json`：本次证据与文件清单。

## 检查接入

```powershell
python codex-share/install.py --check
```

返回 checked 说明规则与技能文件已接入；同时查看 warnings。它不能替代一次实际需求验收，也不保证每个项目都安装了浏览器、数据库或文档工具。

完整执行仍需要目标项目源码、相应工具和当前 Codex 授权。流程一致指工作步骤和证据口径一致，不保证不同模型产生完全相同的代码，也不把环境缺失视为通过。

v1 的未跑通 Worker 已移除，未恢复原项目目录。v2 是手动提示词包；v3 增加原生项目规则接入。业务原件、密钥、数据库和私人运行日志均不纳入分享载荷。
