# 一致流程的含义与边界

## 可以复用的内容

初始化后，目标项目根的有效指令文件引用 WORKFLOW.md，新会话会据此处理代码需求：理解、修改、选择校验、复核和记录。两项配套技能与模板提供具体指导，FDE 上下文仅作为示例。

复制后的一次初始化是接入原生指令发现机制所需动作。普通子目录中的 Markdown 不会自动变成父项目指令；本包没有绕过该限制。

## 不等于固定模型输出或强制测试平台

这是指令约定，没有后台调度器或额外模型运行器。不同模型、用户要求、全局指令、子目录覆盖规则、可用工具和数据会影响执行细节。它不能保证每次同样的代码或所有检查都可以运行。

目标项目源码、依赖、浏览器、数据库、Word 或外部服务由目标项目准备。缺依赖按未验证记录；不能从 --check 的成功或 ZIP 完整性推导需求通过。

如果更具体的目录规则改变了流程，Codex 应遵循适用规则并记录差异。与安装副本不同的同名 Skill 会保留，需要评估本地内容的兼容性。

## 版本修正

v1 错将未跑通的 Worker 作为入口，已移除。v2 提供手动提示词和记录模板。v3 新增一次性接入、项目根指令、只读自检与隔离安装测试，实际验证范围记录在 PACKAGE-CHECKS.md。

本包没有复制 FDE 全部源码、私人会话设置或历史原始产物，也没有恢复原项目已删除的目录。示例记录只能展示写法，不能代替新需求证据。
