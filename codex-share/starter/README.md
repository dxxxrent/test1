# 项目级 Skills

把 .agents/skills/ 下的两个目录合入目标项目的 .agents/skills/。复制前比较同名文件；不要覆盖已有项目约定。

- document-driven-code-workflow：需求文档分析、任务分类、实现和来源追踪。
- git-ui-playwright：从实际 Git 修改映射到用户操作，复用项目本机浏览器与测试夹具进行有范围的 UI 验证。

这些是当前已安装技能的原样副本，没有捆绑运行器。它们依赖当前 Codex 能读取源码并使用任务所需工具；特定工具或浏览器不会随 SKILL.md 安装。

任务入口见分享包 prompts/full-task.md。
