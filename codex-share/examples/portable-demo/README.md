# 可自行重复的迁移小项目

seed/ 是迁移演示中的初始代码和原有验收断言。它包含一个待修复的原生 Node ESM 搜索函数，运行测试应为 2 项通过、4 项失败。

1. 将 seed/ 的内容复制到一个新的独立代码项目目录；不要在分享包内部直接把它当作项目接入。
2. 将整个 codex-share 文件夹放到该项目根目录，执行 python codex-share/install.py。
3. 在该项目根目录新建 Codex 会话，提出下面的普通需求。
4. 核对源码修改、npm test 的结果以及 docs/testing/ 中的实际记录。

需求原文：

> 请修复搜索函数：查询需要忽略首尾空白和大小写；空查询返回全部；非字符串查询抛出清楚的 TypeError；保持输入数组和条目不变。按本项目约定完成。

示例使用当前支持 --test-isolation=none 的 Node；本次验证为 v24.21.0。seed 的 npm test 采用独立复核实际执行过的无进程隔离命令，以避开 Windows 沙箱对子进程的限制。它只使用原生 node:test 和 assert，不安装依赖、不使用模型替身或业务服务。

本次实际 Codex 迁移运行使用的原始 npm test 是默认 node --test，遇到 spawn EPERM 后如实记录并运行了直接断言；随后独立复核使用这里的无隔离命令通过全部原有断言。具体见[迁移证据](../../evidence/portability-20261022.md)，不是对所有其他项目的成功保证。
