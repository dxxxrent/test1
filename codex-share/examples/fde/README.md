# FDE 实际上下文与记录示例

project-context/ 保存打包时的 CODEBUDDY.md、CONTEXT.md、DESIGN.md 和 Bridge package.json 原样快照，用于理解业务约定、界面规范和真实检查入口。

records/ 保存两份原样历史记录：

- private-document-delete-20261022.md：实现、权限、数据一致性、定向测试、HTTP/浏览器验证与截图索引。
- newbuild-toc-20261021.md：Word 目录与分页问题修复、产物一致性、逐页查看和未执行检查说明。

这些记录展示 FDE 如何写证据，并不证明当前分享包或新需求已经验收通过。记录里引用的源码、截图、生成文件、临时数据库和原始日志未一并打包。文件里的历史命令和绝对/相对路径保持来源原文，迁移时需要适配。
