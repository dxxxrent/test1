# 新建类目录与实际页码

## 问题与修改

原目录将预先列出的标题写成普通段落，TOC 域缺少页码结果，生成后未执行排版刷新。标题编号依赖正文的多级列表，所以纯文字缓存还会遗漏“第一章”“1.1”等实际编号。

现在在正文渲染完成后读取实际 Heading 1–3 段落，创建带内部书签和超链接的原生 Word 目录。目录保留标题原文及正文层级，不使用历史参考文件的目录。三级目录样式统一右对齐页码与点引导线，取消正文网格对目录行高的拉伸。

新增 `newbuild_toc.py` 和 `refresh_newbuild_toc.ps1`。候选稿保存后、预检及哈希/台账计算前，Windows 上的 Word 隐藏实例仅处理输出的临时副本，刷新目录、重新分页，并逐条比较目录页码与标题书签实际所在页。目录标题顺序、正文段落/样式和表格文本复核一致后才复制回输出文件；保留工作区原有文件权限。

排版引擎不可用、超时或复核失败时，保留原生可刷新目录，页码显示“待刷新”，在校验问题清单中记录 `TOC-PAGINATION-PENDING`，不填估算页码。当前自动分页实现使用 Windows Microsoft Word；其他环境保留待刷新状态。排版过程不读取外部链接、不启用宏，并恢复 Word 的原链接更新选项。超时清理只处理本次新建且 PID、创建时间仍匹配的 Word 实例。
